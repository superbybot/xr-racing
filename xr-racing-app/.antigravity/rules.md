# Unity Project Rules for Antigravity

## Reference project: xr-sandbox

This project's implementation leans heavily on
`/Users/byronbautista/xr-sandbox/xr-sandbox-app`
— it's a sister sandbox project with the XR driving rig, Meta XR SDK setup,
and a Unity Karting Microgame reference already worked out, and is where the
assets currently in `xr-racing-app/Assets/App/References/` were ported from.

Don't hesitate to look there when deciding how to implement something here —
check its scripts, prefabs, and package setup for existing patterns before
building from scratch. Treat it as a reference/source, not something to edit.
